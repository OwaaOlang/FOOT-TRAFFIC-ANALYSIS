## 1. Week 11 - Weather App with Air Quality

A Python app that shows real-time weather + air quality for Yei, South Sudan and any city.

**What it does:**
- Gets current weather from OpenWeatherMap API
- Gets Air Quality Index (AQI) from OpenWeatherMap Air Pollution API
- Shows temperature, humidity, wind, and condition
- Shows 3-day forecast
- Saves report to `yei_weather_report.json`

**Files:**
- `week11_weather/weather_app_with_air_quality.py` - Main app with weather + air quality
- `week11_weather/day3_final_submission.py` - Earlier version

**How to run:**
```bash
pip install requests
cd week11_weather
python weather_app_with_air_quality.py

## Day 10: Live Exchange Rate Tracker
Built a Python script that fetches live forex rates from open.er-api.com

### Features
- Fetches live USD base rates (160+ currencies)
- Converts KES, UGX, SSP, GHS, ZAR etc to USD
- Error handling for status code & invalid currency codes


### How to Run
pip install requests
cd week12_exchange_tracker
python week12/exchange_tracker.py

Example:
Enter code: UGX
Live Rate: 1 USD = 3820 UGX
